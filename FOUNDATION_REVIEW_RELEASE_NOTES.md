# Tibia Toolkit 0.6.2 - corrective release

This corrective release restores the complete Biblioteca content bundle and
adds release gates that prevent runtime assets or local catalogs from being
omitted from future content-pack promotions.

This is a public, unsigned release published for transparency and the initial
SignPath Foundation review. The installer is built by GitHub Actions from the
annotated source tag and is intentionally not Authenticode-signed yet.

Windows may show a SmartScreen warning until a future signed release is
available. Verify the installer with `SHA256SUMS.txt` before use.

[Code signing policy](https://github.com/poioso/tibia-toolkit/blob/main/docs/CODE_SIGNING_POLICY.md)
